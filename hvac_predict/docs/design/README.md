# Design docs

A design doc works through a large or contested choice before it is decided: the options, how each measures against the requirements, and what would settle it. Once the choice is made the doc is frozen, and the decision goes into a record in [`../adrs/`](../adrs/) that links back to it.

No design doc is open. The choices still to be made are listed under "Open questions" in [`../architecture/overview.md`](../architecture/overview.md); one of them that needs more than a paragraph to settle belongs here.
