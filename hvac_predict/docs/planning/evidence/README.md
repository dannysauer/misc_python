# Evidence

Dated receipts that prove a claim made elsewhere in the docs, such as test output, a simulation result, or a run against the real thermostat.

Name each receipt `YYYY-MM-DD-short-claim.<ext>`, using the date the evidence was captured. A receipt is not edited once it is committed. When newer evidence replaces older evidence, add the new receipt beside the old one and update the page that cites it.

A receipt that proves a requirement names the requirement's ID, such as `HVP-003`, so the quality-attributes page can cite it.
